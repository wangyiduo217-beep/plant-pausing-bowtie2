# 分析方法与适用范围

本仓库整理植物 GRO-seq 的 Bowtie2 处理流程：已下载 SRA 转换为 FASTQ、按建库协议剪切、可选 rRNA 过滤、基因组比对、BAM 排序与基本质控。代码从项目正在使用的流程提取为便携实现；生产流程的参数沿革与验证边界见 [production-provenance.md](production-provenance.md)。

## 适用的输入

以一个 SRR 为执行单位，以实验或生物学样本为后续汇总单位。同一生物学重复拆成多个 SRR，不能因此算成多个独立重复。当前研究选择野生型、未接受生物学处理的普通 GRO-seq；体外 run-on 条件不同的对照应单独分组，不能直接混入主训练集。

本仓库仅实现 **Bowtie2** 分支。生产项目中的 **GSE181488 使用 HISAT2**，不应通过改写配置将它强行纳入这里的 Bowtie2 分支。PRO-seq、5′ GRO-seq、pNET-seq 等其他技术，也不能仅因与新生转录有关就套用相同端点解释。

参考 FASTA、注释和索引应属于同一物种、组装版本和染色体命名体系。已有索引不意味着不同版本的参考可以互换；记录参考版本与校验值是复现的一部分。

## SRA 转换与协议检查

生产流程使用 `fasterq-dump --split-3`。双端数据期望得到 R1、R2；若另有未配对的生物学 reads，必须先检查来源，不能默默丢弃。原始 SRA 的完整性检查与 FASTQ 转换是否成功是两个独立检查。

原始 FASTQ 探针检查前 100,000 条记录的长度、碱基质量编码范围和常见接头或 poly(A) 序列。该抽样用于发现协议问题，不替代完整文件校验，也不能据此推断所有 reads 的污染比例。

## 剪切参数

常规 Cutadapt 参数为 `-q 20 --max-n 0.1`，最终最短长度为 25 nt。`-q 20` 在这里用于 3′ 端质量剪切。接头和 poly(A) 设置按项目读取配置，不设置所有项目通用的强制接头。

- 普通接头搜索使用最短重叠 8 nt、允许错误率 0.1。
- 配置 `--poly-a` 的项目使用 Cutadapt 的 poly(A) 尾处理。
- GSE181598 将 `A{10};min_overlap=10` 作为一个 3′ 接头参数，用于去除内部实验性 poly(A) 及其后面的序列。这里的 10 nt 最短重叠覆盖常规 8 nt 设置；它与仅剪掉末端 poly(A) 的行为不同。
- NEXTflex 配置先剪接头并要求至少 33 nt，再对每个 mate 的 5′ 和 3′ 端各去掉 4 nt，最后要求至少 25 nt。第二步使用 `-u 4 -u -4`，双端数据同时使用 `-U 4 -U -4`。这仅适用于已核对的随机碱基结构。

Pausing 分析依赖片段端点。没有协议证据时不能统一剪掉 5′ 端若干碱基；有随机碱基时也不能把它们误作真实转录序列。项目特异规则以及已完成的修正见生产来源记录。

## rRNA 过滤

若提供与项目参考一致、非空的注释 rRNA 序列及 Bowtie2 索引，使用 `--very-sensitive` 比对 rRNA，丢弃 SAM 输出，保留未被本步骤判定需排除的 FASTQ。

单端使用 `--un-gz`。双端使用 `--no-mixed --no-discordant --un-conc-gz`：**仅排除能作为 concordant pair 比对至 rRNA 的成对 reads**。保留下来的 pair 仍可能有单独一端匹配 rRNA；这个步骤不是穷尽的 rRNA 去除。注释 rRNA 参考本身也可能不完整。

生产 rRNA 步骤未额外添加基因组步骤的 `-X 1000` 或 `--dovetail`，复现时应保持两个阶段的区别。本仓库未配置 `rrna_index` 时记录为未做 rRNA 过滤；配置了该字段但索引缺失或含空分片时会报错。生产旧流程对空 rRNA 参考采用跳过策略，不能把这种跳过报告为“rRNA 已清除”。

## 基因组比对与 BAM

基因组 Bowtie2 使用 `--very-sensitive --end-to-end`。读组 ID 对应 SRR，`SM` 对应实验编号。单端使用 `-U`；双端使用 `-1/-2 --no-mixed --no-discordant -X 1000 --dovetail`。这里没有启用局部比对或任意 5′ 端剪切。

SAM 直接传给 `samtools sort`，排序内存参数为 `-m 1G`，并分别检查比对和排序两个进程的退出状态。输出坐标排序 BAM 后运行 `samtools quickcheck`，创建 **CSI 索引**（`samtools index -c`）。小麦含超过 BAI 单参考序列坐标范围的长染色体，因此不能把 CSI 随意换回默认 BAI。

全部排序 BAM 保留比对结果与未比对记录，另生成高可信主比对 BAM：

```text
samtools view -b -q 20 -F 2820
```

`2820 = 4 + 256 + 512 + 2048`，分别排除未比对、secondary、QC fail 和 supplementary 记录。**不排除 duplicate 标记 1024，也不执行坐标去重。** MAPQ ≥ 20 是当前筛选阈值，不代表每条记录已被证明来源唯一。筛选逐条 BAM 记录执行，没有额外要求完整成对保留或 proper-pair 标记。

Pausing 热点中多个真实分子可能有相同坐标。在缺少经核对的 UMI 或其他分子证据时，不能把全部同坐标 reads 当成 PCR 重复。保留重复并不等于重复偏倚已经解决，仍需后续评估。

## 质控与计数口径

基本输出包括 `flagstat`、`idxstats`、剪切报告、FastQC 和完整命令日志。FastQC 的接头项通过不代表全部质控通过；序列组成、重复度或过度富集项需结合 GRO-seq 建库特点解释。`quickcheck` 是基本结构检查，不能单独证明 BAM 所有内容无误或生物学结果可靠。

下游统计须区分：

| 计数 | 含义 |
|---|---|
| SRA / SRR 数 | 测序运行文件数 |
| 成对 reads 数 | 双端数据的片段对数 |
| BAM 记录数 | 比对文件中的记录数；双端不等于片段数或分子数 |
| 生物学重复数 | 独立样本数，需要由实验元数据判定 |

当前 BAM 保留核基因组、叶绿体、线粒体以及参考中的其他序列。核基因组统计需要显式选择相应染色体，不能把总比对数直接称为可用于 pausing 的核基因组信号。

完成比对不等于已获得最终深度学习输入。还需核对链方向、每种协议的读段端点定义、有效核基因组覆盖、重复一致性、批次差异与标签构建；同一样本或同源实验的不同 SRR 不应跨训练和验证集造成信息泄漏。
